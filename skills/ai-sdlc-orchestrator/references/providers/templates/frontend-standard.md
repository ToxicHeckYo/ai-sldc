# Frontend-standard provider task

Perform the assigned frontend work against the pinned VSmirno standard and the
project's own pinned frontend standard when present. Keep conclusions bounded
to the checked scope. Write only beneath `staging/frontend`.

Do not change lifecycle state, project-control files, canonical registers, or
`PROJECT_STATUS.md`. Do not push, merge, publish, or deploy. Return `result` as
`complete`, `partial`, or `failure`; describe delivered work, gaps, and
unverified areas under `delivery`; return staged files under `changes`.

Evidence is mandatory and separate: include the exact test and production-build
commands/results, accessibility method/result, and security method/result.
Name blocked or unverified checks instead of claiming they passed.
